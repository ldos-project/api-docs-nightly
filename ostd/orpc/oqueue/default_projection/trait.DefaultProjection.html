Expand description

Supplies the value exported for an OQueue message when using register_with.

The DefaultProjection derive recursively projects fields that implement this trait. POD values project to themselves; mark fields that should be opaque identifiers with #[projection(opaque)], which projects them through OpaqueId, or omit fields with #[projection(omit)]. POD values that cannot implement Projectable (due to orphan rules) can be annotated with #[projection(self)] to produce the same behavior.
