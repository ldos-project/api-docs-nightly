fn select_block_device( &self, selection: BioCandidates<'_>, ) -> Result<Arc<dyn BlockDevice>, Error>

Chooses the member device to read from among the admitted candidates.

The policy must return one of the devices whose index appears in selection.candidates. If the policy cannot decide, for whatever reason, this should return an error; the caller will use some fallback.
