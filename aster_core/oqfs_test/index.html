Module oqfs_test 

Source
Expand description

Regression-test support for the OQFS file operations (produce, consume, strong_observe, and weak_observe).

When enabled via the oqfs_test.enable kernel command-line flag, this module registers three OQueues under the oqfs_test OQFS subtree and spawns a single kernel thread. That thread blocks on the trigger queue and, each time userspace writes to trigger/produce, produces the batch 0..BATCH into the observe queue, which userspace reads through strong_observe or weak_observe. The userspace_produce_consume queue is produced and consumed entirely in userspace; the kernel only keeps it alive.

The userspace drivers under test/initramfs/src/regression/oqfs/ drive the queues through the /oqueues/oqfs_test/... filesystem and verify the values they observe.
