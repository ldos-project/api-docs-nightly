Struct LockingWeakObserver

struct LockingWeakObserver<T> {
    oqueue: Weak<LockingQueue<T>>,
    max_observed_tail: Cell<usize>,
    _oqueue_ref: Arc<dyn Any + Send + Sync>,
}
Expand description

A weak observer for a locking OQueue. This only works with ObservableLockingQueue since otherwise the values would have been moved out instead of cloned.

fn weak_observe(&self, cursor: Cursor) -> Option<T>

Observe the data at the given index in the full history of the oqueue. If the data has already been discarded this will return None. This is guaranteed to always return either None or the actual value that existed at the given index.
