Module pi_futex_events 

Source
Expand description

The futex.pi.events OQueue, which reports how threads contend on PI futexes.

Together with scheduler.events, this lets a policy see who waits on whom. Every event carries an optional snapshot of the current owner and its scheduling policy. Block details name the waiter and its policy, while WaitEnd and Handoff details report how long the wait lasted and who the lock went to.

Event delivery never waits for observers. If a strong observer’s ring is full, the event is dropped. The queue is exported at /oqueues/futex/pi/events.
